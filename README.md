# FastForm 填写记忆 · 使用说明

油猴脚本，挂在内网页上。联调用：记住表单、一键回填、空字段造测试数据、切测试账号、抓接口、把复现 bug 的操作录下来。

当前脚本：`youhou.js`（v1.8.0）

生效地址：

- `http://192.168.120.228/*`
- `http://192.168.100.156/*`

两个环境按 **页面路径** 共用历史，不跟 IP 走。换台机器只要路径一样，导入 JSON 就能接着用。

---

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge 都行）。
2. 油猴图标 → **添加新脚本**。
3. 删掉编辑器里的默认内容，把仓库里的 `youhou.js` **全文粘进去**。
4. `Ctrl+S` 保存，确认脚本已启用。
5. 打开上面两个内网地址之一，右下角应出现六边形悬浮球。

改完脚本后：油猴后台点一下 **重新加载**，再刷新页面。版本号在菜单标题 `CMD GRID v1.8.0` 上。

页面没有球：确认地址匹配、脚本已启用、页面是 http 不是 https。

## 日常场景

### 联调弹窗：填一遍，下次一键回来

1. 打开新增 / 编辑弹窗，把表填好。
2. `Alt+S` 或菜单「保存」，可写备注。
3. 下次打开同一页、同一个弹窗，`Alt+F` 回填最新一条。

有弹窗时 **只写弹窗里的表**，外面的查询条件不会被改掉。

只要某几列：`Shift`+点「回填」，或历史里点「勾选」。

### 空表冒烟：不想手填

1. 打开空弹窗。
2. `Alt+V` 打开虚拟预览（只填空字段，已有内容不动）。
3. 核对，可全选 / 反选，点「写入」或按 `Enter`。

虚拟会按字段名 / 标签猜类型：手机、姓名、邮箱、身份证、日期、金额、地址等。下拉有选项时选第一项。密码、验证码、上传会跳过。

只要某一格：在输入框上 **右键** →「虚拟此字段」。

### 换测试账号

1. 打开登录页，填好账号密码。
2. 菜单「身份」→「保存」。先起名称，再填 **项目分组**（如「海宁监控」），用来区分项目。
3. 之后在任意页打开「身份」，点「切换」：会退出当前用户并登录该身份。

有验证码时只填账号密码，不自动点登录。密码只存在油猴本地，不会进页面历史。

顶部可按项目筛选。行内「项目」输入框能改分组。同一账号可以属于不同项目。选中某组时点「清空」，只清这一组。

### Token 脏了、字典不对

菜单「重置」或 `Alt+R`，确认后会清本站 `localStorage` / `sessionStorage` / Cookie / Cache Storage 并刷新。

**会留下**：填表历史、身份档。  
**清不掉**：HttpOnly Cookie。那种还得在开发者工具里手动清，或用浏览器的清除站点数据。

### 跟后端对接口

1. 打开菜单「抓包」（`Alt+N`）。
2. 在页面上点查询 / 提交，列表里会出现最近的接口（最多 40 条）。
3. 点一行展开请求 / 响应。
   - **复制**：整条 JSON
   - **cURL**：带当前 token，可丢给后端
   - **写入**：请求体对上字段后填进当前表
   - **响应**：用返回的 `data` 回填（适合拿详情接口填编辑弹窗）

静态资源、心跳会丢掉。只存在内存，**刷新页面就没了**。

菜单「复制」复制的是 **本页表单历史**，和抓包不是一回事。

### 复现 Bug 录给别人

1. 点「录制」（`Alt+E`），球变红，标签 `REC`。
2. 按出问题的路径操作：怎么移鼠标、点了哪个按钮、填了哪一格，都会记下（**包括提交**）。
3. 再点一次「录制」，起个名字保存。
4. `Shift`+点「录制」或 `Alt+Shift+E` 打开本页列表：
   - **回放**：红点光标按轨迹走，并真实点击。会先确认。`Esc` 可停。
   - **导出**：复制完整 JSON。别人打开**同一路径**的页面，列表里点「导入」，即可回放。
   - **步骤**：纯文字「1. 点击「新增」…」，可贴进缺陷单，不能回放。

对方需要：同样装了这份脚本、能打开同一内网地址、进的是录制时的那条路径。列表会显示录制时的 **屏幕分辨率、窗口大小、缩放**；回放时若不一致会提醒。差太多时点击可能偏，尽量调成一样再回放。

每页最多 12 条。回放会真的点到提交，不要在正式数据上随便回放。

### 换电脑接着用

本页历史：菜单「复制」→ 到另一台同一页「导入」。  
录制：列表里「导出」→ 另一台同一页「导入」。  
身份档要在登录页重新保存。抓包只在当前页内存，刷新即丢。

## 菜单

| 编号 | 名称 | 快捷键 | 做什么 |
| --- | --- | --- | --- |
| 01 | 保存 | `Alt+S` | 记下当前页识别到的表，可写备注。每页最多 30 条 |
| 02 | 回填 | `Alt+F` | 写入最新一条。`Shift`+点 / `Alt+Shift+F` 先勾选 |
| 03 | 虚拟 | `Alt+V` | 只给空字段造数，先预览再写 |
| 04 | 历史 | — | 本页档案：搜索、回填、勾选、复制、改备注、删除、清空本页 |
| 05 | 复制 | — | 把最新一条表单 JSON 拷到剪贴板 |
| 06 | 导入 | — | 从剪贴板读 JSON，写入历史并回填 |
| 07 | 身份 | `Alt+U` | 测试账号，按项目分组，切换登录 |
| 08 | 重置 | `Alt+R` | 清站点缓存和 token，然后刷新 |
| 09 | 抓包 | `Alt+N` | 本页最近接口 |
| 10 | 录制 | `Alt+E` | 开始/停止复现录制。`Shift`+点打开列表 |

历史里 `Esc`：有搜索词时先清空搜索，再按一次才关面板。

## 写入时怎么认表

优先顺序：

1. FastForm `getValues` / `setValues`
2. Element Plus / Vant 表单
3. 原生 `input`

有弹窗、抽屉时只写最上层弹窗里的表。

虚拟 / 普通回填 **跳过**：密码、验证码、上传、Element Plus 内部 id（`el-id-*`）。切身份登录时可以写账号密码。

## 数据存在哪

| 数据 | 范围 | 刷新后 | 换浏览器 |
| --- | --- | --- | --- |
| 本页填表历史 | 按路径，两套 IP 共用 | 还在 | 要复制/导入 |
| 身份档 | 全局，按项目分组 | 还在 | 要重新保存 |
| 抓包 | 仅当前页内存 | 没了 | — |
| 录制 | 按路径 | 还在 | 要重新录 |

历史和身份主要写在油猴 `GM_*` 里，并顺带写一份 `localStorage`。点「重置」不会删它们。

---

## 注意

- 这是开发辅助，不要对着正式环境回放「提交 / 删除」。
- iframe 里的表目前认不到。
- 下拉、级联、日期：页面上还没有选项时，虚拟填不了第一项。
- 复杂联动（选 A 才出现 B）可能漏字段，再虚拟一次或右键补那一格。
- 快捷键是 `Alt+字母`。若和浏览器或系统快捷键冲突，改用菜单。
- 脚本只匹配上面两个内网 IP。换了环境要改 `youhou.js` 文件头的 `@match`，并升高 `@version` 和代码里的 `VERSION`。
